# Staff Page (Test Task)

A staff directory page with search, filtering by department/role, sorting, and pagination.  
Data is served by a mocked API (no real backend).

[**Live Demo →**](https://deemoor.github.io/test-task-staff/)

## Tech Stack
React · TypeScript · Vite  
MUI · MUI X Data Grid  
Axios · axios-mock-adapter

## Getting Started
```bash
npm install
npm run dev      # http://localhost:5173
```
